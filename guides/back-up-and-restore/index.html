Your family’s data

Back up and restore your data

Save a snapshot of the family data you own, or return to a saved snapshot when you need it.

Save a manual backup

  1. Open Settings > Export Data Backup.

    Create the backup from the parent account that owns the children you want to include.

  2. Choose where to keep the backup file.

    Save it somewhere you can find again, such as iCloud Drive. Keep the JSON file intact so AllowanceKit can import it later.

Export Transactions (CSV) is for opening history in a spreadsheet. Use Export Data Backup for a file you can restore into AllowanceKit.

Turn on automatic backups

  1. Open Settings > Automatic Backups.

    Choose Weekly or Monthly under Frequency.

  2. Let iCloud syncing finish.

    When a backup is due, it is saved the next time you open the app after syncing. Backups aren’t guaranteed while the app stays closed.

  3. Check “Last saved”.

    You can also tap Check Backup Now to check whether a backup is due. Files are saved in iCloud Drive > AllowanceKit > Automatic Backups. Uploading to your other devices can take longer.

Restoring replaces your current owned family data. Children, buckets, goals, transactions and backed-up preferences return to the selected snapshot. Owned data created after that snapshot is removed, and changes sync to your family’s devices. Export a fresh backup first if you may need to return to your current data.

Restore a saved backup

  1. Choose your backup.

    For a manual file, open Settings > Import Data Backup. For an automatic snapshot, open Settings > Automatic Backups and choose a date under Restore Backup. Use Refresh Backups if needed.

  2. Read the confirmation carefully.

    Check the backup’s date and contents. Selecting a backup does not immediately replace anything. Automatic restores wait for iCloud syncing to settle first.

  3. Confirm only when you’re ready to replace the data.

    Allow the restore to finish, then check your balances and history. Keep the other family devices online so changes can sync.

What stays the same?

Children shared with you by another parent are left untouched. Your parent PIN and child codes stay as they are; restoring a backup does not reset a forgotten PIN. Use PIN recovery for that.

Do I need Premium?

Backup creation and export are free. Restoring a backup with more than one owned child requires Premium; a single-child backup can be restored on the free plan.

Turning automatic backups off keeps existing backup files. You can manage those files separately in the Files app.
