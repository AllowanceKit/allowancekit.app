Child access

Reset a child’s code

A child’s four-digit code keeps siblings out of their view on a shared phone or tablet. A parent can change or remove it from Settings.

Check the screen first. A screen with your child’s name asks for their code. A screen titled “Parent PIN” asks for your parent PIN. If you forgot that one, use parent PIN recovery.

Change the code

  1. Return to parent mode on the device with the forgotten code.

    Use the lock button or the parent-mode option and enter your parent PIN. If you’re at the child-code screen, “Forgot code? Ask a parent” lets a parent authorize entry to the child’s view; then use the lock button to return to parent mode.

  2. Open Settings > Child Codes.

    Select the child whose code you want to change.

  3. Tap “Change code”.

    Enter a new four-digit code, then enter it again to confirm. You don’t need the old child code.

  4. Try the new code in kid mode.

    Let your child know their new code. If you prefer to stop asking for one, choose Remove code instead.

Which devices change?

Child codes are stored separately on each device. Changing a code on the family iPad doesn’t change one on another phone. Your child’s balances and history aren’t changed.

A child’s own locked device

Changing a child’s code does not unlock a device configured as their own. To reclaim that device, use the parent-approval steps.

If the child is read-only

Code changes require permission to edit that child. Check sharing permissions and the owning parent’s Premium access if editing is unavailable. Read about Premium access.
